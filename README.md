# RDMO Plugins

This repository contains a list of the currently available [RDMO](https://rdmorganiser.github.io/) plugins.

For additional information, please refer to the [corresponding documentation](https://rdmo.readthedocs.io/en/latest/plugins/index.html).

## Plugins maintained by RDMO

| [maDMP](https://github.com/rdmorganiser/rdmo-plugins-madmp)             |                                              | inactive | [Export](https://rdmo.readthedocs.io/en/latest/plugins/index.html#project-export-plugins), [Import](https://rdmo.readthedocs.io/en/latest/plugins/index.html#project-import-plugins) | This repo contains and export and an import plugin to provide interoperability of [RDMO](https://github.com/rdmorganiser/rdmo) with the [RDA-DMP-Common-Standard (maDMP)](https://github.com/RDA-DMP-Common/RDA-DMP-Common-Standard).                                                                                                                                                                                                                                                    |

| [Zenodo](https://github.com/rdmorganiser/rdmo-plugins-zenodo)           | [@jochenklar](https://github.com/jochenklar) | active   | [Export](https://rdmo.readthedocs.io/en/latest/plugins/index.html#project-export-plugins)                                                                                            | This plugin implements an [export provider](https://rdmo.readthedocs.io/en/latest/plugins/index.html#export-providers) for RDMO, which lets users push metadata from RDMO to Zenodo. It creates only the metadata in Zenodo, so users need to upload the actual data to Zenodo themselves.                                                                               |

The plugin uses [OAUTH 2.0](https://oauth.net/2/), so that users use their respective accounts in both systems. |
| [GitLab](https://github.com/rdmorganiser/rdmo-plugins-gitlab)           |                                              | active   | [IssueProvider](https://rdmo.readthedocs.io/en/latest/plugins/index.html#issue-providers), [Import](https://rdmo.readthedocs.io/en/latest/plugins/index.html#project-import-plugins) | The plugin implements an [issue provider](https://rdmo.readthedocs.io/en/latest/plugins/index.html#issue-providers), which lets users push their tasks from RDMO to GitLab issues, and an [project import plugin](https://rdmo.readthedocs.io/en/latest/plugins/index.html#project-import-plugins), which can be used to import projects from (public or private) repos. The plugin uses [OAUTH 2.0](https://oauth.net/2/), so that users use their respective accounts in both systems. |
| [OpenProject](https://github.com/rdmorganiser/rdmo-plugins-openproject) | [@jochenklar](https://github.com/jochenklar) | active   | [IssueProvider](https://rdmo.readthedocs.io/en/latest/plugins/index.html#issue-providers)                                                                                            | This plugin implements an [issue provider](https://rdmo.readthedocs.io/en/latest/plugins/index.html#issue-providers) for RDMO, which lets users push their tasks from RDMO to OpenProject work packages. The plugin uses [OAUTH 2.0](https://oauth.net/2/), so that users use their respective accounts in both systems.                                                                                                                                                                 |
